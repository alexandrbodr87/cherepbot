Череповец News Bot
Автоматизированный бот для сбора и публикации актуальных новостей Череповца.
Описание
Бот предназначен для автоматического мониторинга источников, парсинга новостей и их публикации в Telegram-канал. Позволяет оперативно оповещать аудиторию о событиях в городе без ручного вмешательства.
Основные возможности
 Авто-парсинг: Регулярная проверка новостных источников.
 Публикация: Автоматическая отправка сообщений в канал с форматированием.
Технологии
 Язык: Python 3.x
 Основные библиотеки: ⁠aiogram⁠, ⁠requests⁠, ⁠BeautifulSoup4⁠
